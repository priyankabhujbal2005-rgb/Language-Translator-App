# 🌐 Language Translator App

A simple web-based language translation application built using **React.js**, **FastAPI**, **Python**, and a free translation API.

## 📌 Project Overview

The Language Translator App allows users to enter text, select a source language and a target language, and get the translated text.

The application provides a simple and user-friendly interface for performing text translation.

## ✨ Features

- 🌐 Translate text between different languages
- 📝 Text input for the original content
- 🔄 Source and target language selection
- 📋 Display translated text
- 💻 Simple and user-friendly interface
- ⚡ React-based frontend
- 🚀 FastAPI backend
